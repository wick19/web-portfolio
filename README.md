- React 18 + Vite
- Custom carbon/cyan UI
- Content driven from `src/customization/*.json`

## Local development

```bash
npm install
npm run dev
```

## Deploy

```bash
npm run deploy
```

Publishes the `dist` build to GitHub Pages (`gh-pages`).
