Boston Home Prices through MLP

PyTorch Scikit-learn Pandas Numpy
code

This project implements a Multi-Layer Perceptron (MLP) to solve a complex regression task: predicting median house values in Boston. The model leverages 13 distinct input variables including environmental factors (nitric oxides concentration), structural attributes (average rooms per dwelling), and socio-economic indicators (crime rate per capita).

Core Challenge

Mapping non-linear relationships between fragmented urban datasets and real-estate valuation metrics using deep learning architectures.

Outcome

Achieved a significantly lower Mean Squared Error compared to baseline linear models through hyperparameter tuning and layer normalization.
